# io_redirections_and_filters

Ce dossier contient les scripts du projet sur les redirections et les filtres.

## Scripts

- **0-hello_world** : affiche "Hello, World" suivi d'un retour a la ligne sur la sortie standard.
- **1-confused_smiley** : affiche le smiley "(Ôo)'.
- **2-hellofile** : affiche le contenu du fichier /etc/passwd.
- **3-twofiles** : affiche le contenu des fichiers /etc/passwd et /etc/hosts.
- **4-lastlines** : affiche les 10 dernieres lignes du fichier /etc/passwd.
- **5-firstlines** : affiche les 10 premieres lignes du fichier /etc/passwd.
- **6-third_line** : affiche la troisieme ligne du fichier iacta.
- **7-file** : cree un fichier au nom complexe contenant des caracteres speciaux et y ecrit Best School.
- **7-file** : cree un fichier au nom special contenant le texte Best School.
- **9-duplicate_last_line** : duplique la derniere ligne du fichier iacta.
- **10-no_more_js** : supprime tous les fichiers .js (pas les dossiers) du dossier courant et de ses sous-dossiers.
