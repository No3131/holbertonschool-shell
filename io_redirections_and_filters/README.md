# io_redirections_and_filters

Ce dossier contient les scripts du projet sur les redirections et les filtres.

## Scripts

- **0-hello_world** : affiche "Hello, World" suivi d'un retour a la ligne sur la sortie standard.
- **1-confused_smiley** : affiche le smiley "(Ôo)'.
- **2-hellofile** : affiche le contenu du fichier /etc/passwd.
- **3-twofiles** : affiche le contenu des fichiers /etc/passwd et /etc/hosts.
- **4-lastlines** : affiche les 10 dernieres lignes du fichier /etc/passwd.
- **5-firstlines** : affiche les 10 premieres lignes du fichier /etc/passwd.
- **6-third_line** : affiche la troisieme ligne du fichier iacta.
- **7-file** : cree un fichier au nom complexe contenant des caracteres speciaux et y ecrit Best School.
- **7-file** : cree un fichier au nom special contenant le texte Best School.
- **9-duplicate_last_line** : duplique la derniere ligne du fichier iacta.
- **10-no_more_js** : supprime tous les fichiers .js (pas les dossiers) du dossier courant et de ses sous-dossiers.
- **11-directories** : compte le nombre de dossiers et sous-dossiers du dossier courant (dossiers caches inclus).
- **12-newest_files** : affiche les 10 fichiers les plus recents du dossier courant, un par ligne, du plus recent au plus ancien.
- **13-unique** : lit une liste de mots (un par ligne) et affiche, tries, ceux qui n'apparaissent qu'une seule fois.
- **14-findthatword** : affiche les lignes du fichier /etc/passwd qui contiennent le motif root.
- **15-countthatword** : affiche le nombre de lignes du fichier /etc/passwd qui contiennent le motif bin.
- **16-whatsnext** : affiche les lignes du fichier /etc/passwd qui contiennent le motif root et les 3 lignes qui suivent.
- **16-whatsnext** : affiche les lignes du fichier /etc/passwd qui contiennent le motif root et les 3 lignes qui suivent.
- **17-hidethisword** : affiche les lignes du fichier /etc/passwd qui ne contiennent pas le motif bin.
- **18-letteronly** : affiche les lignes du fichier /etc/ssh/sshd_config qui commencent par une lettre (majuscule ou minuscule).
- **19-AZ** : remplace tous les caracteres A par Z et c par e dans l'entree.
- **20-hiago** : supprime toutes les lettres c et C de l'entree.
